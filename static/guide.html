강의자료랑 기출만 있으면,
예상문제는 저희가 만들게요.

PDF 두 종류를 올리면 기출의 유형과 형식을 닮은 새 문제를 만들어 드립니다. 뼈 이름만 외우고 싶은 날엔 아무것도 준비하지 않아도 됩니다. 이 문서는 처음 오신 분이 헤매지 않도록, 화면에 보이는 것 그대로 순서대로 설명합니다.

준비물 · PDF 2종 첫 문제까지 약 5분 설치 없이 브라우저에서

처음이라면, 이 세 가지만

1
먼저 로그인하세요 (오른쪽 위 로그인)

안 해도 다 쓸 수 있습니다. 다만 로그인 없이 만든 기록은 나중에 로그인해도 계정으로 옮겨지지 않습니다. 남겨 둘 생각이면 시작 전에 하는 게 편해요.

2
API 키를 붙여넣으세요

문제를 만들려면 AI를 불러야 하고, 그때 쓰는 열쇠입니다. 어디서 받는지는 키 입력칸 바로 아래 발급 방법을 펼치면 나옵니다. 키를 넣으면 쓸 수 있는 모델 목록이 저절로 채워져요.

3
PDF를 올리고 ✨ 예상문제 생성하기

강의자료와 기출문제, 두 칸 모두 채워야 시작됩니다. 나머지 설정은 전부 기본값 그대로 두셔도 괜찮아요.

🌿
처음엔 문제 3~5개로 한 번 돌려 보세요. 결과가 마음에 들면 그때 개수를 늘리면 됩니다. 같은 자료로 두 번째부터는 훨씬 빠르고, 토큰도 훨씬 적게 씁니다.

📝 문제 생성

이 사이트의 중심 기능입니다. 제목을 누르면 자세한 설명이 펼쳐집니다.

📄

어떤 파일을 올리면 되나요

준비물

강의자료(교수님 슬라이드·필기본)와 기출문제를 각각 올립니다. 기출을 보고 "이 과목은 이런 식으로 묻는구나"를 배운 다음, 강의자료 내용으로 새 문제를 씁니다. 그래서 두 종류가 모두 있어야 시작됩니다.

항목제한
형식PDF만 가능합니다 (ppt·한글 파일은 PDF로 저장해서 올려주세요)
개수강의자료 최대 7개, 기출 최대 7개
용량둘을 합쳐서 500MB까지 — 화면에 적힌 숫자가 정확한 값입니다
문제 수한 번에 1~30개
🔒
올린 PDF는 서버에 쌓이지 않습니다. 읽는 동안만 잠깐 두었다가 끝나면 바로 지웁니다. 남는 건 파일이 아니라 분석 결과뿐이에요.
💡
파일 개수를 줄이면 한 파일에 배정되는 분량이 늘어 더 깊게 읽습니다. 300쪽짜리 하나가 30쪽짜리 일곱 개보다 나을 때가 많아요.
⏳

만드는 동안

몇 분 걸려요

진행 상태가 네 단계로 보입니다. 자료가 많으면 몇 분씩 걸리는 게 정상이에요.

  1. PDF 텍스트 추출 — 글자를 뽑습니다. 그림으로 된 페이지는 AI가 눈으로 읽어 설명을 남깁니다.
  2. 강의·기출 핵심 개념 분석 — 무엇이 중요한지 정리합니다.
  3. 기출 예시 추출 · 형식 분석 — 기출이 어떤 말투로 묻는지 배웁니다.
  4. 예상문제 생성 — 문제가 하나씩 완성되는 대로 화면에 나타납니다.
🚶
기다리는 동안 골학 문제은행이나 보관함으로 옮겨 다녀도 됩니다. 문제는 그대로 만들어져요.
⚠️
브라우저 탭을 닫거나 새로고침하면 중단됩니다. 이것 하나만 조심하세요. ■ 중지로 직접 멈출 수도 있지만, 그때까지 쓴 토큰은 돌려받을 수 없습니다.

「일부 파일이 분량 상한을 넘습니다」 창이 떴다면 — 자료가 읽을 수 있는 분량보다 길어서 일부가 잘린다는 뜻입니다. 이대로 진행을 눌러도 되고(앞부분과 뒷부분을 남깁니다), 파일을 줄여 다시 하셔도 됩니다.

💡
이 창은 바깥을 눌러도 닫히지 않습니다. 실수로 배경을 눌러 이미 토큰을 쓴 작업이 날아가는 걸 막으려고 일부러 그렇게 만들었어요. 이대로 진행을 눌러도 PDF를 다시 읽지 않으니 토큰이 두 번 나가지 않습니다.
💾

같은 자료로 또 만들 때 — 저장된 세션

가장 유용

한 번 분석한 자료는 그 분석 결과가 자동으로 저장됩니다. 다음부터는 저장된 세션에서 고르고 바로 만들면, 가장 오래 걸리고 토큰을 가장 많이 쓰는 분석 단계를 통째로 건너뜁니다. 시험 기간에 같은 범위를 여러 번 돌릴 때 체감이 큽니다.

  • 세션을 고르면 초록색 띠가 뜨고, 버튼이 이 세션으로 문제 생성 (분석 생략)으로 바뀝니다.
  • ✏️로 이름을 바꾸고, 🗑️로 지웁니다. 세션을 지우면 그 세션으로 만든 문제 기록도 함께 사라집니다.
  • 홈 화면 맨 아래 이어서 하기는 가장 최근 세션입니다. 홈에서 버튼 한 번이면 바로 생성까지 갑니다.
💡
세션을 고른 상태에서 새 파일을 올리면 세션이 저절로 해제되고, 반대로 세션을 고르면 올려둔 파일이 비워집니다. 둘이 섞여서 엉뚱하게 다시 분석되는 일이 없도록 한 장치예요.

🔍 기출 주제 분석

"이 두꺼운 강의록에서 대체 어디가 나왔던 거지?" 에 대한 답.

🗺️

무엇을 해 주나요

문제는 안 만듭니다

강의록의 주제 중 기출에 실제로 나온 것만 골라 어느 강의록 몇 페이지 → 어느 기출 몇 번 형태로 이어 줍니다. 주제 이름은 강의록에 적힌 표현 그대로 쓰기 때문에, 결과를 들고 바로 그 페이지를 펼칠 수 있어요.

  • 올리는 방법과 제한은 문제 생성과 같습니다 (PDF · 각 7개 · 합쳐서 500MB).
  • 🔎 걸러보기에 단어를 치면 주제·파일명·기출 원문까지 한 번에 찾습니다.
  • 📋 한 줄 요약 보기를 펼치면 주제: 강의록 12p - 기출 4번 형태의 목록이 나오고, 전체 복사 버튼으로 통째로 복사해 노션이나 단톡방에 붙일 수 있습니다.
💡
같은 자료를 다시 올리면 "이미 분석한 결과가 있습니다" 창이 뜹니다. 보관된 결과 열기는 토큰을 한 개도 쓰지 않습니다. 특별한 이유가 없으면 이쪽을 고르세요.
📷
결과가 하나도 안 나왔다면 대개 두 경우입니다. 강의록과 기출의 범위가 서로 다르거나, PDF가 통째로 스캔 이미지라 페이지·문항 번호를 읽을 수 없거나. 근거를 확인할 수 없는 주제는 지어내지 않고 빼기 때문입니다.

생성한 문제 · 분석한 주제

자동 저장됨

보관함에 들어가면 두 갈래가 나옵니다. 만든 문제 세트와, 분석한 주제입니다. 둘 다 따로 저장하지 않아도 알아서 쌓여 있어요.

  • 한 페이지에 8장씩, 최신순으로 보입니다.
  • 어떤 자료(세션)로 만든 것인지 기준으로 걸러 볼 수 있습니다.
  • 카드에서 이름 변경 ✏️, 삭제 🗑️, 인쇄 🖨.
  • 한 장을 열면 그때 쓴 토큰·크레딧 기록도 함께 볼 수 있습니다.
🖨

인쇄하거나 PDF로 저장하기

스터디용

시험지를 열면 버튼이 두 개입니다. 🖨 문제지와 🖨 정답·해설. 한 번에 두 벌을 저장할 수는 없으니 각각 한 번씩 눌러주세요.

🙈
문제지에는 정답이 절대 딸려 나가지 않습니다. 화면에서 정답을 다 열어본 뒤에 인쇄해도 마찬가지예요. 스터디에서 나눠 주기 전에 확인하지 않으셔도 됩니다.
  • 정답지는 위에 번호-정답 한눈표, 아래에 문항별 해설이 실립니다. 채점할 땐 위쪽만 보면 끝나요.
  • 빈칸 문제는 손으로 쓸 수 있게 밑줄로 바뀝니다.
  • 인쇄 창에서 「머리글 및 바닥글」을 끄면 URL과 날짜가 빠져 깔끔합니다. 대신 페이지 번호도 같이 사라집니다.
📱
카카오톡이나 인스타그램 안에서 링크를 열면 인쇄 창이 안 뜰 수 있습니다. 그럴 땐 오른쪽 위 메뉴에서 Safari나 Chrome으로 열어 주세요.

❌ 오답 노트

틀린 걸 모아두는 폴더. 여기에 담는 건 전부 내가 직접 고른 것뿐입니다.

🔖

담고, 모아 보고, 다시 풀기

토큰 안 씀
  1. 문제 옆 🔖 오답에 넣기를 누릅니다.
  2. 기존 폴더를 고르거나, 새 폴더 이름을 지어 담습니다. (예: 순환기 오답)
  3. 오답 노트 탭에서 폴더를 열면 원래 문제 그대로 다시 풀 수 있습니다.
  • 생성한 문제도, 골학 문제은행 문제도 그림째로 담을 수 있습니다.
  • 폴더는 이름 변경·삭제가 되고, 문제는 🗑️ 폴더에서 빼기로 하나씩 뺍니다.
💡
골학 오답은 번호 그림과 이름이 적힌 원본 그림이 함께 저장됩니다. 오답 노트에서도 🖼️ 원본 보기로 정답 위치를 바로 확인할 수 있어요.

점수는 화면에서만 세고 어디에도 보내지 않습니다. 새로고침하면 초기화돼요. 마음 놓고 틀리셔도 됩니다. 남기고 싶은 문제만 🔖로 담으세요.

안심하셔도 되는 것들

처음 오신 분들이 가장 많이 물어보시는 것부터.

올린 PDF는 안 쌓여요 읽는 동안만 잠깐 두었다가 끝나면 바로 지웁니다. 혹시 오류로 남더라도 한 시간 안에 자동으로 치워집니다.
API 키는 저장하지 않아요 서버에도, 브라우저에도 남기지 않고 요청에 쓰고 버립니다. 새로고침하면 다시 입력해야 하는 게 그 증거예요.
내 기록은 나만 봐요 세션·문제·주제·오답은 전부 내 계정(또는 내 브라우저)에만 묶여 있습니다.
저장 버튼을 찾지 않아도 돼요 만든 문제도, 분석 결과도 자동으로 보관함에 들어갑니다.
기다리는 동안 딴짓해도 돼요 다른 탭으로 옮겨 다녀도 작업은 계속됩니다. 탭을 닫거나 새로고침하는 것만 피하세요.
실수로 토큰이 새지 않아요 토큰을 쓰는 확인 창은 바깥을 눌러도 닫히지 않고, 같은 자료는 저장된 결과를 먼저 권합니다.
골학은 완전히 공짜예요 키도 로그인도 필요 없고 토큰도 안 듭니다. 점수도 서버로 보내지 않아요.
문제지에 정답이 안 섞여요 인쇄용 문제지에는 정답 글자가 애초에 들어가지 않습니다.

토큰을 아끼는 요령

토큰(전북대 플랫폼이라면 크레딧)을 쓰는 건 문제 생성과 기출 주제 분석 둘뿐입니다. 효과가 큰 순서대로.

  1. 저장된 세션을 쓰세요. 같은 자료라면 두 번째부터 토큰을 가장 많이 쓰는 분석 단계를 통째로 건너뜁니다.
  2. 같은 자료 재분석 창에서는 「보관된 결과 열기」. 주제 분석은 이걸로 토큰을 한 개도 쓰지 않습니다.
  3. 한 번에 넉넉히 만드세요. 30문제 한 번이 6문제씩 다섯 번보다 토큰을 적게 씁니다.
  4. 파일 개수를 줄이세요. 잘려 버려지는 부분이 줄어 같은 값으로 더 깊게 읽습니다.
  5. 그림이 많은 스캔 기출은 토큰을 많이 먹습니다. 페이지마다 AI가 눈으로 읽어야 하거든요. 급하지 않다면 글자가 살아있는 PDF를 쓰세요.
🛑
■ 중지를 눌러도 이미 쓴 토큰은 돌려받을 수 없습니다. 중지는 남은 호출을 멈출 뿐이에요.

거의 항상 API 키 문제입니다. 키를 다시 확인하고 옆의 ↻ 버튼을 눌러보세요. 고른 제공사와 키가 같은 곳의 것인지도 확인해 주세요 — 다른 회사 키를 넣으면 목록을 불러오지 못합니다.

새로고침했더니 API 키가 비어 있어요

정상입니다. 키를 아예 저장하지 않기 때문이에요. 조금 번거롭지만, 그 덕분에 키가 어딘가에 남아 있을 걱정을 하지 않아도 됩니다. 다시 붙여넣어 주세요.

만들다가 멈췄어요 / 결과가 안 와요

탭을 닫거나 새로고침하면 중단됩니다. 그게 아니라면 자료가 너무 많아 시간이 오래 걸린 경우일 수 있어요 — 수백 쪽짜리 스캔본을 한꺼번에 올리면 도중에 연결이 끊길 수 있습니다.

파일 수를 줄이거나, 강의자료를 나눠서 여러 번 돌려 보세요.

업로드가 거부돼요

세 가지를 확인해 주세요. PDF가 맞는지, 강의자료·기출이 각각 7개 이하인지, 둘을 합친 용량이 제한 아래인지. 제한 용량은 업로드 칸 아래 노란 안내에 정확한 숫자로 적혀 있습니다.

휴대폰에서 파일 선택 창이 비어 보여요

PDF만 고를 수 있게 걸러진 상태라 다른 파일이 안 보이는 것입니다. 구글 드라이브 같은 클라우드에 있는 파일은 먼저 휴대폰에 내려받은 뒤 고르면 잘 잡힙니다.

기출 주제 분석 결과가 하나도 없어요

강의록과 기출이 같은 과목·같은 범위인지 먼저 확인해 주세요. 그리고 PDF가 통째로 스캔한 이미지라면 페이지·문항 번호를 읽을 수 없어 결과가 비어 나옵니다.

근거를 확인할 수 없는 주제는 그럴듯하게 지어내는 대신 빼도록 만들어져 있습니다.

다른 기기에서 보니 기록이 없어요

로그인하지 않고 만든 기록은 그 브라우저에만 남습니다. 로그인한 뒤에 만든 것부터 기기 사이를 따라다녀요.

안타깝지만 이미 만들어 둔 게스트 기록을 계정으로 옮기는 방법은 없습니다. 중요한 자료라면 지금이라도 로그인한 뒤 다시 만들어 두시는 편이 낫습니다.

답이 맞는 것 같은데 오답으로 나왔어요

골학은 대소문자·띄어쓰기·하이픈·괄호를 모두 무시하지만, 철자가 다른 동의어는 등록된 것만 인정합니다. 억울한 경우가 있으면 팀에 알려 주세요 — 정답 목록에 추가할 수 있습니다.

생성된 문제의 답은 AI가 쓴 것이라 가끔 애매할 수 있습니다. 해설을 함께 보시고, 이상하면 🔖로 담아두었다가 교재로 확인해 보세요.

만들어진 문제가 이상해요

AI가 쓰는 문제라 완벽하지 않습니다. 기출 반영 강도를 8~10으로 올리면 기출에 가깝고 안정적인 문제가 나오는 편입니다.

강의자료 대신 목차나 표지만 있는 PDF를 올렸거나, 기출이 실제로는 다른 과목이면 결과가 크게 흔들립니다. 올린 파일부터 확인해 보세요.
