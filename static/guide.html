👤 로그인

  • Google 계정으로 로그인합니다.
  • 로그인 상태에서는 생성한 문제, 파일 분석 결과, 기출 주제 분석 결과, 오답 노트가 계정에 저장됩니다.
  • 비로그인 상태에서도 모든 기능을 이용할 수 있지만, 기록이 브라우저에만 저장되어 다른 기기에서는 접근할 수 없습니다.
  • 비로그인 상태에서 생긴 기록은 추후 로그인하더라도 계정으로 이동되지 않습니다. 다만 로그아웃 후에는 다시 해당 기록에 접근할 수 있습니다.

🔑 API 키 발급

문제 생성과 기출 주제 분석에 필요합니다. 사용하는 제공사를 눌러 펼쳐보세요.

전북대 LLM 게이트웨이
  1. gpt.jbnu.ai에 로그인합니다.
  2. 왼쪽 메뉴 최하단의 "API Gateway"로 들어갑니다.
  3. "API 키 관리"에서 [ + API 키 생성 ] 버튼을 누르고, 이름은 아무거나 적습니다.
  4. 생성된 API 키를 복사해 메모장에 저장해둡니다. 창을 닫으면 키를 다시 확인할 수 없습니다.
  5. 복사한 키를 문제 생성·기출 주제 분석 탭의 API 키 입력칸에 붙여넣으세요.

🔗 전북대 LLM 게이트웨이 키 발급 페이지 열기

OpenAI
  1. platform.openai.com에 로그인합니다. (ChatGPT 계정과 같은 계정으로 로그인됩니다)
  2. 왼쪽 메뉴에서 API keys를 엽니다.
  3. Create new secret key 버튼을 누르고, 이름은 아무거나 적어도 됩니다.
  4. 키는 이때 딱 한 번만 보입니다. 창을 닫으면 다시 볼 수 없으니 바로 복사해서 문제 생성·기출 주제 분석 탭의 API 키 입력칸에 붙여넣으세요.
  5. Billing 메뉴에서 결제 수단을 등록하고 크레딧을 충전해야 실제 호출이 됩니다.
💡
ChatGPT Plus 구독료와 API 요금은 별개입니다. Plus를 쓰고 있어도 API 크레딧은 따로 충전해야 합니다.

🔗 OpenAI 키 발급 페이지 열기

Anthropic (Claude)
  1. console.anthropic.com에 로그인합니다. (Claude.ai 계정과 같은 계정으로 로그인됩니다)
  2. Settings → API keys로 들어갑니다.
  3. Create Key 버튼을 누르고, 이름은 아무거나 적어도 됩니다.
  4. 키는 이때 딱 한 번만 보입니다. 창을 닫으면 다시 볼 수 없으니 바로 복사해서 문제 생성·기출 주제 분석 탭의 API 키 입력칸에 붙여넣으세요.
  5. Billing 메뉴에서 크레딧을 구매해야 실제 호출이 됩니다.
💡
Claude Pro 구독료와 API 요금은 별개입니다. Pro를 쓰고 있어도 API 크레딧은 따로 구매해야 합니다.

🔗 Anthropic (Claude) 키 발급 페이지 열기

Google Gemini
  1. aistudio.google.com에 Google 계정으로 로그인합니다.
  2. API 키 만들기(Get API key) 버튼을 누릅니다.
  3. 프로젝트를 고르라고 하면 아무거나 골라도 되고, 새로 만들어도 됩니다.
  4. 만들어진 키를 복사해서 문제 생성·기출 주제 분석 탭의 API 키 입력칸에 붙여넣으세요. (여기서는 나중에 다시 볼 수 있습니다)
💡
무료 등급이 있어서 결제 수단 없이도 바로 써볼 수 있습니다. 다만 분당·일당 요청 수에 제한이 있습니다.

📝 문제 생성

강의자료와 기출문제 파일을 업로드하면 예상 문제를 생성합니다.

지원 형식PDF 파일
개수강의자료 7개 · 기출 7개
용량강의자료+기출 총 500MB
생성 문제 수한 번에 1~30개
  • 텍스트 추출 → 개념 분석 → 기출 형식 분석 → 문제 생성 4단계로 진행되며, 문제는 완성되는 대로 하나씩 표시됩니다.
  • 자료가 길면 내용 일부가 잘릴 수 있습니다. 이 경우 텍스트 추출이 끝난 후 안내 창이 표시됩니다.
  • ■ 중지를 눌러도 이미 쓴 토큰은 환불되지 않습니다.
  • 저장된 세션 — 강의자료와 기출문제 분석 결과가 자동 저장되어, 이후에는 같은 파일로 문제를 생성할 때 분석 단계를 건너뛰고 빠르게 문제를 생성할 수 있습니다.
  • 세션을 삭제하면 그 세션으로 만든 문제 기록도 삭제됩니다. 저장된 세션에 새 파일을 업로드할 수 없습니다.
⚠️
탭을 닫거나 새로고침하면 중단됩니다. 다른 탭으로 이동하는 건 괜찮습니다.

🔍 기출 주제 분석

기출에 실제로 나온 주제만 골라 강의록 몇 페이지 → 기출 몇 번으로 연결합니다.

  • 파일 업로드 용량 제한은 문제 생성과 같습니다(총 500MB).
  • 📋 한 줄 요약 보기를 누르면 서로 대응되는 강의록/기출문제 페이지 번호 목록만 간단히 표시됩니다. 전체 복사 버튼을 눌러 복사할 수 있습니다.
  • 결과가 비어 있다면 강의록과 기출문제의 범위가 일치하지 않는 것입니다.

🗂️ 보관함

생성된 문제와 기출 주제 분석 결과가 최신순으로 자동 저장됩니다.

  • 🖨 문제지 · 🖨 정답·해설 버튼을 눌러 인쇄하거나 PDF로 저장할 수 있습니다.
  • 문제지에 정답은 표시되지 않습니다.
  • 카카오톡·인스타그램 인앱 브라우저에서는 인쇄 창이 뜨지 않습니다. Safari·Chrome으로 열어주세요.

❌ 오답 노트

생성된 문제 / 골학 문제은행에서 🔖 오답에 넣기 버튼을 눌러 오답 노트를 만들 수 있습니다.

  • 폴더를 만들어 오답을 폴더별로 관리할 수 있습니다.
  • 토큰을 사용하지 않습니다.

🦴 골학 문제은행

각 부위에 번호가 매겨진 뼈 그림이 제시되고, 해당 번호에 맞는 부위 이름을 주관식으로 입력해야 합니다.

  • 선택한 범위 안에서 중복 없이 랜덤으로 출제됩니다.
  • Skull · Upper Limb · Lower Limb · Vertebrae & Thorax 또는 Random(전체) 범위 중 하나를 선택할 수 있습니다.
  • 채점할 때는 대소문자·띄어쓰기·하이픈을 무시하고, 동의어는 등록된 것만 인정됩니다.
  • 채점 결과는 저장되지 않습니다(새로고침 시 초기화).

🔒 데이터 처리

  • 업로드된 PDF 파일 — 분석 중에만 보관하고, 끝나면 즉시 삭제됩니다. 오류로 남아도 1시간 내 자동 삭제됩니다.
  • API 키 — 서버·브라우저 어디에도 저장하지 않습니다. 새로고침하면 다시 입력해야 합니다.
  • 내 기록 — 세션·만든 문제·주제 분석 결과·오답은 내 계정에만 귀속됩니다.
  • 저장 — 생성된 문제·주제 분석 결과 모두 자동으로 보관함에 저장됩니다.

💰 토큰 절약 방법

토큰을 사용하는 기능은 문제 생성과 기출 주제 분석뿐입니다.

  1. 문제 생성 시 저장된 세션 재사용 — 가장 비용이 많이 드는 분석 단계를 건너뜁니다.
  2. 문제는 한 번에 넉넉히 생성하기 — 6문제 X 5회 (X) → 30문제 X 1회 (O)
  3. 파일 개수 줄이기 — 잘려 버려지는 부분이 감소합니다.
  4. 스캔본 PDF는 피하기 — AI가 읽는 비용이 많이 듭니다.

❓ FAQ

모델 목록이 안 떠요

API 키를 확인하고 옆의 ↻를 누르세요. 고른 제공사와 키 발급처가 같아야 합니다.

새로고침했더니 API 키가 비어 있어요

키를 저장하지 않기 때문입니다. 다시 입력해 주세요.

생성이 멈췄어요 / 결과가 안 와요

탭을 닫거나 새로고침했거나, 자료가 많아 연결이 끊긴 경우입니다. 파일 수를 줄이거나 강의자료를 나눠서 돌려 보세요.

업로드가 거부돼요

PDF인지, 각각 7개 이하인지, 합친 용량이 제한(500MB) 아래인지 확인하세요.

휴대폰에서 파일 선택 창이 비어 보여요

PDF만 보이도록 걸러진 것입니다. 클라우드에 있는 파일은 먼저 휴대폰에 내려받은 뒤 고르세요.

기출 주제 분석 결과에 아무것도 표시되지 않아요

강의록과 기출이 같은 과목·같은 범위인지 확인하세요.

다른 기기에서 보니 기록이 없어요

비로그인 기록은 그 브라우저에만 남고 추후 로그인하더라도 계정으로 옮길 수 없습니다. 중요한 자료라면 로그인 후 다시 만들어 두세요.

만들어진 문제가 이상해요

기출 반영 강도를 8~10으로 올리면 안정적입니다. 목차·표지만 있는 PDF이거나 기출이 다른 과목이면 품질이 크게 떨어지니 올린 파일부터 확인하세요.
