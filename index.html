로그인 없이도 모든 기능을 쓸 수 있어요. 다만 만든 기록이 어디에 남는지가 달라집니다.
✅ 로그인하고 쓰면
저장된 세션 · 문제 생성 이력 · 오답 노트가 계정에 저장됩니다. 다른 기기나 브라우저에서 로그인해도 그대로 이어서 볼 수 있어요.
⚠️ 로그인 없이 쓰면
기록이 이 브라우저에만 임시로 보관됩니다. 쿠키를 지우거나 시크릿 창을 닫으면 사라지고, 다른 기기에서는 보이지 않아요.
※ 로그인 없이 만든 기록은 나중에 로그인해도 계정으로 옮겨지지 않습니다. 남겨두고 싶다면 시작 전에 로그인하세요.
🔒 API 키는 로그인 여부와 관계없이 서버·브라우저에 저장되지 않습니다.
